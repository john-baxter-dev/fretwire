# fretwire

Placeholder crate reserving the `fretwire` name on crates.io.

**fretwire** is an independent, community-built application for editing Line 6 HX Stomp
presets and parameters from Linux over USB. The device control protocol was recovered by
observing USB traffic. This project is **not affiliated with or endorsed by** Line 6 or
Yamaha Guitar Group, and is provided **with no warranty** — use at your own risk.

This crate is intentionally empty. The working code lives in the `fretwire-*` crates and
the `fretwire` command-line tool.
